# Vouchers & Achievements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Balatro's 32 vouchers, sold in the shop with one voucher per stage, plus 16 addon-internal achievements that gate the upgraded vouchers. Includes an achievements view, toasts and a boss reroll.

**Architecture:**
- Voucher defs are data (`Data/Vouchers.lua`).
- A pure `Core/Vouchers.lua` answers "what does the run's voucher set change?" through small query functions. Shop, Run, Packs and Scoring consult those functions, so effects are not scattered across flags.
- Lifetime counters and achievements live in `Core/Profile.lua`.
- Core emits events through `ns.Profile.onEvent(name, amount, run)`. The UI binds that hook to the DB, exactly like `onObtain`.

**Tech Stack:** Lua 5.1 (LuaJIT tests), WoW Mainline API (Retail plus Forever 16001), Python stdlib for textures.

**Spec:** `docs/superpowers/specs/2026-11-06-vouchers-design.md`. Voucher names, effects and unlock conditions come from its table, corrected by its "Calls made after review" section; where they conflict, the calls section wins.

## Global Constraints

- **Lua and globals:**
  - Lua 5.1 only. Every file starts with `local _, ns = ...`.
  - The only globals are `AzerothAnteDB`, `SLASH_AZEROTHANTE1` and `SlashCmdList.AZEROTHANTE`.
- **Core and Data:**
  - Core and Data never call the WoW API or reference `AzerothAnteDB`.
  - All randomness goes through `run.rng`.
  - Run and profile state are plain data.
- **Saves:** `Save.VERSION = 3`. Loading a v2 save MIGRATES it by adding defaults; it must not be invalidated.
- **UI rules:**
  - Use `frame:IsMouseOver()`, never the global MouseIsOver.
  - Feature-guard optional APIs.
  - Card art uses `SetTexCoord(..., Theme.cardV)`.
  - All new UI uses the Theme helpers (Inset, Raised, Selected, Button, Label, Value, Edge).
- **Prices:**
  - Voucher base cost is $10.
  - Discount price = `max(1, floor(cost*(1-d)+0.5))`. It applies to shop cards, packs and vouchers, never to rerolls or the boss reroll.
  - Sell value = `floor(paid/2)`. The price paid is stored on the item as `paid`.
- **Smoothness:** the anti-goal is clunkiness, so every new interaction is animated and nothing gets stuck.
- **Suites:** keep all four green: `luajit tests/run.lua`, `luajit tests/smoke_ui.lua`, `luajit tests/syntax.lua`, `python3 tests/test_media.py`.

## Review Focus

1. **A v2 save mid-run loads after the update**, with every new run field defaulted and the run playable. Pinned in Task 1 by `v2_save_migrates`.
2. **A deck unlocked under the old thresholds stays unlocked** after the thresholds rise. Pinned in Task 4 by `grandfathered_unlocks`.
3. **Hieroglyph bought at stage 1** charges $10, applies its penalty and leaves stage at 1. Pinned in Task 3 by `hieroglyph_floor`.
4. **The boss reroll when every pool boss has been fought** still gives a different boss and never Ragnaros. Pinned in Task 3 by `boss_reroll_exhausted_pool`.
5. **A discount on a $1 item** still costs at least $1, and sell values never exceed half the price paid. Pinned in Task 2 by `discount_floor_and_sell`.

    - Ids are the Balatro names upper-snake: OVERSTOCK, OVERSTOCK_PLUS, CLEARANCE_SALE, LIQUIDATION, HONE, GLOW_UP, REROLL_SURPLUS, REROLL_GLUT, CRYSTAL_BALL, OMEN_GLOBE, TELESCOPE, OBSERVATORY, GRABBER, NACHO_TONG, WASTEFUL, RECYCLOMANCY, TAROT_MERCHANT, TAROT_TYCOON, PLANET_MERCHANT, PLANET_TYCOON, SEED_MONEY, MONEY_TREE, BLANK, ANTIMATTER, MAGIC_TRICK, ILLUSION, HIEROGLYPH, PETROGLYPH, DIRECTORS_CUT, RETCON, PAINT_BRUSH, PALETTE.
    - `name` is the WoW name from the spec; `desc` is the effect text.
  - New run fields:
    - `vouchers = {}` (set of owned ids);
    - `shopVoucher = nil|{id, cost}`;
    - `handPlays = {}`;
    - `bossRerollsUsed = 0` (resets each stage);
    - `bossesFought = {}` (set);
    - `streak = {maxInterest = 0}`.
  - Query functions, each taking `run`:
    - `Vouchers.owns(run, id)`;
    - `Vouchers.shopCardSlots(run) -> 2 + overstock count`;
    - `Vouchers.discount(run) -> 0|0.25|0.5`;
    - `Vouchers.price(run, cost) -> int`;
    - `Vouchers.rerollDelta(run) -> 0|2|4`;
    - `Vouchers.editionMult(run) -> 1|2|4`;
    - `Vouchers.scrollWeight(run) -> 4|9.6|32` and `Vouchers.tomeWeight(run)`;
    - `Vouchers.interestCap(run) -> 5|10|20`;
    - `Vouchers.extraHands(run)`, `Vouchers.extraDiscards(run)`, `Vouchers.extraHandSize(run)`, `Vouchers.extraConsumables(run)` and `Vouchers.extraTrinkets(run)`, each `-> int`;
    - `Vouchers.playingCardsInShop(run) -> bool` and `Vouchers.illusion(run) -> bool`;
    - `Vouchers.omenGlobe(run)`, `Vouchers.telescope(run)` and `Vouchers.observatory(run)`, each `-> bool`;
    - `Vouchers.bossRerolls(run) -> 0|1|math.huge`.
    - Hieroglyph and Petroglyph also reduce hands or discards via `extraHands`/`extraDiscards` (−1 each).
  - `Vouchers.onBuy(run, id)`: one-off effects at purchase. HIEROGLYPH and PETROGLYPH set `run.stage = max(1, run.stage - 1)`; every other voucher is a no-op, because the queries read `run.vouchers` live.
  - `Save.VERSION = 3`. `Save.load` accepts v2, adds the new fields with defaults and relinks.

### Task 2: Shop and packs, wired to vouchers

**Files:** Modify `Core/Shop.lua`, `Core/Packs.lua`, `tests/test_shop.lua` and `tests/test_packs.lua`.

**Interfaces:**
- Consumes the Task 1 queries.
- Produces:
  - **Voucher offer:**
    - `Shop.open(run)` sets `run.shopVoucher` if nil, via `Shop.rollVoucher(run)`. The offer is uniform among eligible vouchers: tier 1 not owned, or tier 2 whose base is owned and whose achievement is unlocked. Achievement unlocks are read through a Core hook, `ns.Profile.hasAchievement(achId) -> bool`, which defaults to false when unbound.
    - `Shop.buyVoucher(run) -> ok, err` charges `Vouchers.price`, records `paid`, adds to `run.vouchers`, applies immediate effects via `Vouchers.onBuy(run, id)` (Hieroglyph and Petroglyph stage, slots), sets `shopVoucher = false` and emits `onEvent("voucherBought", 1)` and `onEvent("blankBought", 1)` for BLANK.
    - `Run.winBlind` on a boss win sets `run.shopVoucher = nil`, so the next stage rolls a new one.
  - **Shop cards:**
    - The count is `Vouchers.shopCardSlots`, with type weights trinket 20, scroll `scrollWeight`, tome `tomeWeight`, and playing card 4 when `playingCardsInShop` (Illusion lets it roll enhancement, edition or seal like Standard packs).
    - Edition odds are multiplied by `editionMult`.
    - Prices go through `Vouchers.price`, and every bought item stores `paid`. `Shop.sellValue` uses `paid` when present.
  - **Reroll:** cost = `max(0, rerollCost - rerollDelta)`. It emits `onEvent("reroll",1)` and `onEvent("spend", cost)`.
  - **Buy:** each buy emits `onEvent("spend", paid)`, plus `scrollBought`, `tomeBought` or `cardBought` as relevant.
  - **Packs:**
    - Pack prices go through `Vouchers.price`.
    - With Omen Globe, each Arcana choice has a 20% chance to be a Relic.
    - With Telescope, the first Celestial choice is the Tome for the most-played hand (ties go to the higher-ranked hand in `Hands.order`), or a random visible Tome with zero plays.
    - Picking a Scroll from an Arcana pack emits `scrollFromPackUsed`; a Tome from a Celestial pack emits `tomeFromPackUsed`.
  - **Hook guard:** `ns.Profile.onEvent` is guarded (`if ns.Profile and ns.Profile.onEvent`).

### Task 3: Run, Scoring and the boss reroll, wired to vouchers

**Files:** Modify `Core/Run.lua`, `Core/Deck.lua` (handSize), `Core/Consumables.lua` (slot count) and `Core/Scoring.lua`. Create `tests/test_voucher_run.lua`.

**Interfaces:**
- Consumes the Task 1 queries.
- Produces:
  - **Run stats:**
    - `Run.startBlind` hands and discards include `extraHands` and `extraDiscards`, with a minimum of 1 hand and 0 discards.
    - `Deck.handSize` includes `extraHandSize`.
    - The consumable slot count is `run.maxConsumables + extraConsumables`.
    - `Run.trinketSlots` adds `extraTrinkets`.
  - **Payout:** the interest cap comes from `interestCap`.
    - The payout's interest is `min(cap, floor(gold/5))`.
    - `streak.maxInterest` increments when interest equals the cap and is above 0, and resets otherwise.
    - It emits `onEvent("maxInterestStreak", streak, run)` when it changes.
  - **Hieroglyph and Petroglyph:** `Vouchers.onBuy` sets `run.stage = max(1, stage-1)`.
  - **Play tracking:**
    - `Run.play` increments `handPlays[handId]` and emits `onEvent("cardsPlayed", #cards)`.
    - `Run.discard` emits `onEvent("cardsDiscarded", #idx)`.
    - `Run.startBlind` records `bossesFought[bossId] = true` on blind 3 and emits `onEvent("bossFought", bossId)`.
    - Run end emits `onEvent("runEnded", won and 1 or 0, run)`, so the profile can check "won with Hieroglyph".
    - Blind start emits `onEvent("handSize", Deck.handSize(run), run)` for the Palette check.
    - Changes to the trinket set emit `onEvent("editionTrinkets", count, run)`.
  - **Boss reroll:**
    - `Run.canRerollBoss(run) -> ok, reason` is false when stage 8, the phase isn't "blind", `bossRerollsUsed >= Vouchers.bossRerolls(run)`, or gold is under 10.
    - `Run.rerollBoss(run) -> ok, newBossId` charges $10 (undiscounted), increments `bossRerollsUsed` and picks via run.rng from `Bosses.pool` minus the current boss minus `bossesFought`, falling back to the pool minus the current boss.
    - `bossRerollsUsed` resets on `nextBlind` into a new stage.
  - **Observatory:**
    - In `Scoring.score`, for each Tome in `ctx.consumables` (pass `run.consumables` from `Run.play`) whose hand equals the played hand, apply ×1.5 mult after trinkets.
    - Emit `{kind="voucher", id="OBSERVATORY", xmult=1.5}`.
    - `Tally` must handle the event: float "×1.5" in the mult colour and pulse the consumable slot. That's a small UI touch, but it's owned here because it's tied to the event kind.
